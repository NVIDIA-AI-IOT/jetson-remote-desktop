# Security Policy

## Reporting a Vulnerability

Please do not report suspected security vulnerabilities through public GitHub
issues, discussions, or pull requests.

Report potential security vulnerabilities in Jetson Remote Desktop privately to
the NVIDIA Product Security Incident Response Team (PSIRT). Follow the current
instructions on NVIDIA's
[Report a Vulnerability](https://www.nvidia.com/en-us/security/report-vulnerability/)
page, which provides a submission portal and the `psirt@nvidia.com` email address.
For email reports, encrypt the report using the NVIDIA public PGP key linked from
that page.

Include the following information where available:

- Repository URL: `https://github.com/NVIDIA-AI-IOT/jetson-remote-desktop`
- Affected release, branch, and commit SHA
- Jetson model, Jetson Linux/JetPack version, and relevant dependency versions
- A description of the issue, potential impact, and required access or conditions
- Steps to reproduce and a minimal proof of concept
- Relevant logs with credentials, pairing secrets, and other sensitive data removed

Use public GitHub issues for non-security bugs and feature requests only. Do not
post vulnerability details or exploit code publicly before coordinated disclosure.
